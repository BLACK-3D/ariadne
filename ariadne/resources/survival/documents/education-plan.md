# Skills and reference preservation plan

Preserve skills, reference provenance and safe practical learning.

Original Ariadne planning card, checked 2026-10-28. This card organizes observations, responsibilities and resources; technical, clinical and installation procedures remain with their cited original sources and qualified practitioners.

- [ ] Inventory practical skills, available instructors, training records and learning priorities.
- [ ] Keep offline references with title, author, edition, source URL and rights information.
- [ ] Prepare printed quick-reference indexes for essential material.
- [ ] Record observations, hypotheses, methods and results for safe, appropriately supervised experiments.
- [ ] Distinguish historical descriptions from current tested procedures.
- [ ] Match learning activities to equipment, supervision and participant ability.
- [ ] Practice teach-back and record questions that require expert review.
- [ ] Keep original source documents available so a generated explanation can be checked.
