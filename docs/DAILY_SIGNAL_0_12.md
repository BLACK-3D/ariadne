# Daily Signal one-page brief

The daily brief has a portrait 1080 × 1350 edition for quick reading, printing and sharing as a single image. Its editorial layout puts saved station weather, the next available forecast periods, recorded activity, up to three regional signals and the next required decision on one page. The full Markdown report and original JSON evidence remain available alongside it.

Open **Daily brief** to view the latest completed brief or select an earlier receipt. **Download PNG** converts the local SVG to a 1080 × 1350 image in the browser; it needs no image service, model or Internet connection. **Download SVG** preserves selectable text and vector lines. **Print one page** opens the browser print dialog using a single A4 portrait sheet. The browser can save that print as a PDF. If local PNG decoding or encoding is unavailable, download the SVG instead; an unsuccessful conversion is reported rather than saved as a completed image.

New scheduled and manual briefs save three individually hashed artifacts: `brief.json`, `brief.md` and `brief.svg`. Existing two-artifact receipts remain readable. The saved SVG uses the brief's generation clock. Its hash belongs to that saved snapshot. The interface derives its preview from the verified original JSON, checks source age again at read time and names that evidence JSON separately; the new preview is not passed off as the original saved SVG's bytes or hash.

The renderer is deterministic and uses only the Python standard library plus the existing compact summary selector. It has no external fonts, images, scripts, model calls or optional rendering dependency. Every preview is exactly one fixed page and at most 36 KB of SVG. Source text is escaped into text elements, never interpreted as HTML or SVG markup. Browser preview uses an image Blob URL, which is released when a report is replaced or the console is locked. Pending report and PNG callbacks cannot restore or download a former authenticated session's content after locking.

Freshness labels distinguish recent saved responses, stale snapshots, failed refreshes and unavailable sources. The source ledger keeps retrieval times and source origins for every selected source entry. Missing weather, forecasts, activity fields and approval status are shown as unavailable rather than invented. Expired saved alerts remain labeled expired; elapsed forecast periods are not selected as upcoming. Empty results never mean an all-clear or comprehensive news coverage. The visible page explicitly identifies omitted content and points to the full report and evidence URLs. Regional source limits and refresh permissions retain their existing behavior.

This format does not inspect activity outside Ariadne. It does not add an Internet refresh, model call, microphone capture or publishing action when a report is viewed or downloaded. Sharing an exported image remains an explicit owner action, and the export can contain private local activity counts and regional information.
