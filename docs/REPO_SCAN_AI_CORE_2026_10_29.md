## Qualification before promotion

Use existing Ariadne tasks and immutable fixtures to compare completed-task correctness, tool selection, citation grounding, unauthorized-action refusal and interruption behavior. Record failures as well as successes. Measure cold start, first usable response, complete response time, peak RAM/VRAM, asset storage and maintenance requirements. For voice, include endpointing, interruption, background noise and the owner's listening preference. No local latency, wattage or monetary savings were measured here.

Keep exact arithmetic and artifact hashes deterministic. An LLM grader is useful for selected subjective checks, but it adds inference work and cannot replace exact output checks. Retain one production controller and load specialist workers on demand. A new framework or model must justify its additional operating burden with observed results.
