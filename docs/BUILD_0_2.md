# Yikes local-box 0.2 work package

Scope: an additive iteration of the standalone Yikes application. No edits, deployment or promotion in C:\Jarvis, C:\Jarvis-Threadline, their worktrees, or E:. No Moonshot phase/campaign acceptance is claimed. Existing Threadline governance snapshots are references, not activation authority.

Deliverables:

- Owner-selected read-only reference folders, bounded document previews, exact-byte hash confirmation and explicit import/refresh into local knowledge.
- Text/CSV/JSON and bounded Office/PDF extraction; imported content remains untrusted reference data.
- Reusable local workflows with owner-authored output checks, artifact hashes and bounded repair feedback. Execution status and file-check status remain separate.
- Deterministic structured-data tools using existing confined file operations.
- Exact owner-authored JSON numeric predicates and weighted `sum_product` totals. Added after the isolated live fixture exposed a wrong weighted value that structural checks alone could not detect; the failed evidence is retained without acceptance credit.
- A capability catalog derived from actual runtime configuration and installed adapters.
- Failure stops for recurring missions and capability binding for persisted approvals.

Permission, credential, approval and verification paths are high risk; source/privacy and storage changes are at least medium risk. Independent verification and adversarial review are required before restarting the existing Yikes server with this update. Builders do not self-certify the reviewed surfaces. No microphone recording, physical control, account connection, spending, public publishing, source-repository execution or arbitrary host shell is part of this work package.

Acceptance evidence: deterministic tests for the new behavior and boundaries; migration compatibility with existing local state; isolated real-model workflow check; local browser QA; separate review records, including limitations and any unresolved findings. Keep the prior running server intact until checks pass and no user mission is active. New code and installation files remain under Yikes.
