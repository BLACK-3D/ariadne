# Ariadne 0.3 work package

The accepted continuation adds three bounded capabilities to the separate Yikes
application: explicitly registered local MCP tools, local OCR for images/scans,
and larger exact table analysis. Changes and installed artifacts stay in Yikes;
E: is excluded. Existing owner authority and substantive-failure stops remain.

MCP uses fixed loopback HTTP destinations, explicit tool allowlists and owner
read/write classifications. Discovery never grants authority. Mutations require
the existing per-call approval bound to current configuration/schema/arguments.
Uncertain remote outcomes stop the mission instead of authorizing retries.

OCR accepts uploaded/reviewed document bytes and pinned local models, without
runtime downloads. Knowledge preserves file hashes and processor identity. A
scan is reference material, never executable instructions or tool authority.

Analytics accepts bounded structured operations over held workspace snapshots,
never model SQL. Native engines load only inside resource-limited workers.
Resource limits do not provide a general operating-system security sandbox.

Completion requires real optional-runtime fixtures, adversarial boundary tests,
independent review of new authority/data paths, browser verification, an idle
local-server upgrade preserving owner state, and a verified source archive.
No external deployment, spending, broad browser automation or host-shell tool
is included in this release.
