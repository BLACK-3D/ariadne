ARIADNE / LOCAL AI / WINDOWS STARTER

Your AI. On your PC.

A private workspace for conversation, useful tools and controlled workflows. Prepare it once online, then use installed local capabilities without Codex or an Internet connection.

Full setup guideOpen running AriadneGitHub repository
This is a starter kit. The initial ZIP contains source and setup scripts. You need Windows x64, Python 3.13 x64 and Internet for the first downloads. Models and optional tool packs are separate assets. Plan for 16 GB RAM and about 30 GB disk for the core as estimates; CPU inference may be slow.
01 / PREPARE

Extract, then set up.

Extract the ZIP to a writable local folder, such as C:\Ariadne. E: and linked folders are excluded. Install Python 3.13, 64-bit, then double-click Setup Ariadne.cmd in that folder.

Wait for setup to finish. It creates the local environment and downloads the default model. Run it only in a fresh installation.

02 / PAIR

Start your own instance.

Double-click Start Ariadne.cmd. Open the local interface. Read your newly created data/server.token in a text editor, and paste that key into the pairing screen.

Keep your key private. Your copy creates its own conversations, files and settings.

03 / EXPLORE

Make something useful.

Start with Service desk and choose Fictional demo for a fictional quote/invoice workflow, or ask a short conversational question.

Use Stop Ariadne.cmd to stop the background host. Closing Codex or the browser does not stop it.

What works without Internet?

The installed model, saved files, memory and deterministic local tools can keep working. New weather, headlines, market data and connected cloud services need Internet. Voice and specialist packs require separate installation; microphone listening, online access and daily schedules are not activated by this starter.

Before a power outage

  1. Complete setup and one local task while online.
  2. Stop Ariadne cleanly.
  3. Test a new launch and the same local task without Internet.
  4. Keep the project, its models, base Python and power available. A fully removable-drive appliance needs a separately qualified bundled runtime; this starter's virtual environment alone is not that appliance.

If something does not start

Open the troubleshooting guide. A missing-runtime error means setup has not completed. If another Ollama owns the model port, close it yourself or follow the advanced source guide; setup will not take it over. Do not turn off security software to work around an error.
