ARIADNE / LOCAL AI / WINDOWS STARTER

Your AI. On your PC.

A private workspace for conversation, useful tools and controlled workflows. Prepare it once online, then use installed local capabilities without Codex or an Internet connection.

This is a starter kit. The initial ZIP contains source and setup scripts. You need Windows 10/11 x64 and Internet for the first downloads. Setup prepares Python inside this folder; no Python, Git, Docker, Node, AI account or administrator setup is required for the core. Models download once; specialist packs remain optional. Plan for 16 GB RAM and about 30 GB disk for the core as estimates; CPU inference may be slow.
01 / PREPARE

Extract, then set up.

Extract the ZIP to a writable local folder, such as a new Ariadne folder inside Downloads. Choose Extract all and open the folder containing README and scripts. E: and linked/network folders are excluded. Double-click Setup Ariadne.cmd in that folder.

Keep Internet connected until setup completes. It prepares private Python, core dependencies and the local model. Use Setup only for a fresh installation; reopen an existing copy with Start.

02 / PAIR

Start your own instance.

After Setup, Check Ariadne.cmd can inspect readiness without downloads or startup. Double-click Start Ariadne.cmd and open the local interface. Read your newly created data/server.token in a text editor, and paste that key into the pairing screen.

Keep your key private. Your copy creates its own conversations, files and settings.

03 / EXPLORE

Make something useful.

Start with Service desk and choose Fictional demo for a fictional quote/invoice workflow, or ask a short conversational question.

Use Stop Ariadne.cmd to stop the background host. Closing Codex or the browser does not stop it.

What works without Internet?

The installed model, saved files, memory and deterministic local tools can keep working. New weather, headlines, market data and connected cloud services need Internet. Voice and specialist packs require separate installation; microphone listening, online access and daily schedules are not activated by this starter.

Before a power outage

  1. Complete setup and one local task while online.
  2. Stop Ariadne cleanly.
  3. Test a new launch and the same local task without Internet.
  4. Keep the complete folder, its bundled runtime, models and power available. Preparing another PC without Internet requires a verified clean offline factory package; this small starter still needs its first downloads.

If something does not start

Open the troubleshooting guide. A missing-runtime error means setup or extraction has not completed; the current starter supplies its own Python. A failed Start keeps its error window and a private diagnostic when safe storage is available. If another Ollama owns the model port, close it yourself or follow the advanced source guide; setup will not take it over. Do not turn off security software to work around an error.

Give another PC an offline core.

After full setup, double-click Prepare Offline Copy.cmd. Keep its new dist/ariadne-offline-core-<UTC>.zip, checksum and receipt together. This is a clean factory copy with Python, core dependencies, Ollama and the pinned model; your conversations, pairing key, clients and private settings stay behind. Optional voice and specialist packs are separate.

Use NTFS/exFAT storage for this many-gigabyte file; FAT32 cannot hold files over 4 GB. Allow space for the ZIP and extraction. On the receiving Windows x64 PC, verify its checksum, Extract all into a new allowed folder and double-click Start Ariadne.cmd. This prepared copy needs no Setup or Internet and creates its own pairing key. The public GitHub starter still needs its initial online downloads.

First useful steps

Open Service desk → Fictional demo → Load fictional examples, review a draft and export its local handoff. Then ask: In three short sentences, tell me what you can do offline. The first response may include loading time.

Download and security checks

Use the official release and its matching checksum. Read Windows warnings and keep security protections enabled. If the folder is incomplete, extract the whole ZIP again into a new folder. Review a held partial download before retrying; preserve existing private data.
